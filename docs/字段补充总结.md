## 注意事项 ⚠️

### 1. 数据库字段顺序
ALTER TABLE 添加的字段会在表末尾，不影响现有应用

### 2. Excel 列顺序
**重要**: Excel 列从第7列改为第8列开始的索引都需要调整！
- 旧: 测试项 index=7
- 新: 班别 index=7, 测试项 index=8

### 3. NULL 值处理
- shift 可以为 NULL
- QMS 接口会发送 `"shift": null`
- 确认 QMS 接口支持 NULL 值

### 4. 历史数据
```sql
-- 查询没有班别的数据
SELECT COUNT(*) FROM SUPPLIER_PROCESS_DATA WHERE SHIFT IS NULL;

-- 可选：为历史数据设置默认值
UPDATE SUPPLIER_PROCESS_DATA SET SHIFT = '未知' WHERE SHIFT IS NULL;
```
