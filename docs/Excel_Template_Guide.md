## 📝 填写说明

### 1. 供应商编码
- 格式: 字母+数字
- 长度: 最多100字符
- 示例: `SUP001`, `VENDOR_A`

### 2. 检测类型
- 格式: 中文/英文
- 长度: 最多100字符
- 示例: `电压测试`, `温度检测`, `外观检查`

### 3. 物料大类
- 格式: 中文/英文
- 长度: 最多100字符
- 示例: `电子元件`, `机械零件`, `化工原料`

### 4. 物料细分类
- 格式: 中文/英文
- 长度: 最多100字符
- 示例: `电阻`, `电容`, `二极管`

### 5. 物料代码
- 格式: 字母+数字
- 长度: 最多100字符
- 示例: `MAT001`, `P/N-12345`

### 6. 工序
- 格式: 中文/英文
- 长度: 最多100字符
- 示例: `测试工序`, `IQC检验`, `来料检测`

### 7. 条码SN
- 格式: 字母+数字
- 长度: 最多200字符
- 示例: `SN123456789`, `BARCODE-001`

### 8. 班别 ⭐ 新增
- 格式: 中文/英文
- 长度: 最多50字符
- 是否必填: **否**（可以为空）
- 常用值: `白班`, `夜班`, `A班`, `B班`, `C班`
- 示例: `白班`, `夜班`, `早班(06:00-14:00)`

### 9. 测试项
- 格式: 中文/英文
- 长度: 最多200字符
- 示例: `电压`, `温度`, `外观`, `尺寸`

### 10. 实际测试值
- 格式: 数字（可以有小数点）
- 精度: 最多6位小数
- 示例: `3.3`, `25.5`, `100.123456`

### 11. 测试过站时间
- 格式: `yyyy-MM-dd HH:mm:ss`
- 示例: `2026-01-24 15:30:00`
- **注意**: Excel 中需要设置单元格格式为"文本"或"自定义日期时间格式"

### 12. 结果
- 格式: 文本
- 长度: 最多50字符
- 常用值: `PASS`, `FAIL`, `OK`, `NG`

### 13. 总结果
- 格式: 文本
- 长度: 最多50字符
- 常用值: `PASS`, `FAIL`, `OK`, `NG`

## ⚠️ 注意事项

### 1. 文件格式
- ✅ 支持 `.xlsx` 格式（Excel 2007及以上）
- ✅ 支持 `.xls` 格式（Excel 2003）
- ❌ 不支持 `.csv` 格式

### 2. 表头要求
- 第1行必须是列名
- 列名必须与模板一致（可以是中文或英文）
- 列的顺序必须正确

### 3. 数据行
- 从第2行开始填写数据
- 空行会被自动跳过
- 最多支持 10000 行数据

### 4. 日期时间格式
- Excel 中设置单元格格式为"文本"
- 或使用自定义格式: `yyyy-mm-dd hh:mm:ss`
- **错误示例**: `2026/1/24 3:30 PM`（会导致解析失败）
- **正确示例**: `2026-01-24 15:30:00`

### 5. 数字格式
- 小数点使用英文句点 `.`
- 不要使用千分位分隔符
- **错误示例**: `3,300.50`
- **正确示例**: `3300.5`

### 6. 班别字段
- **新增字段**，可以为空
- 建议填写，便于后续统计分析
- 常用值: `白班`, `夜班`, `A班`, `B班`, `C班`
- 自定义值: 可以填写任意文本（如 `早班(06:00-14:00)`）

## 🚫 常见错误

### 错误1: 列顺序不正确
```
❌ 错误: 条码SN | 工序 | 班别 | ...
✅ 正确: 工序 | 条码SN | 班别 | ...
```

### 错误2: 缺少必填列
```
❌ 错误: 只有10列数据（缺少班别列后面的列）
✅ 正确: 包含所有13列（即使班别为空）
```

### 错误3: 日期格式错误
```
❌ 错误: 2026/1/24 或 24-Jan-2026
✅ 正确: 2026-01-24 15:30:00
```

### 错误4: 数字格式错误
```
❌ 错误: 3,300.50 或 3.300,50
✅ 正确: 3300.5 或 3300.50
```

## 📥 导入步骤

### 步骤1: 下载模板
从系统下载 Excel 模板文件

### 步骤2: 填写数据
按照本文档说明填写数据

### 步骤3: 检查数据
- 检查列顺序是否正确
- 检查必填项是否都已填写
- 检查日期格式是否正确

### 步骤4: 上传文件
```
POST /api/upload/process-data
Content-Type: multipart/form-data
file: [Excel文件]
```

### 步骤5: 查看结果
系统会返回上传结果，包含：
- 批次号
- 总行数
- 上传状态

## 🎯 最佳实践

### 1. 批量上传
- 建议每次上传不超过 5000 行
- 大文件可以分批上传

### 2. 数据校验
- 上传前用 Excel 筛选功能检查空值
- 确保日期时间格式统一

### 3. 备份数据
- 上传前保存一份原始数据备份
- 记录批次号便于后续追溯

### 4. 班别填写
- 建议统一班别命名规范（如: 白班/夜班）
- 避免使用特殊字符
- 保持一致性
